# CC-149 vetting: the public ledger and band candidates (BL-759)

Lane B, read-only, 2026-10-15. Six repos cloned with `git clone --depth 1` into
`scratchpad/lane-B/<name>/repo`, nothing run from inside any of them, no `claude plugin test`. Every
claim below comes from the manifests, the hooks modules, the shell hook scripts, and the tests, read
in source. Host checked: Claude Code 2.1.300, with `jq`, `sqlite3`, `python3`, and `node` on PATH.

The harness surfaces a candidate can collide with:

- **Shell hooks in `.claude/settings.json`:** PreToolUse on Agent, Write, Edit, NotebookEdit, Bash,
  Monitor, Read, and SubagentHandback; PostToolUse; UserPromptSubmit; SessionStart; Stop with four
  scripts; SubagentStop with three; PermissionDenied; PreCompact; and the project `statusLine`,
  `hooks/statusline.sh`.
- **Installed mods:** `lane-pace` hooks `agent.spawn` and `turn.complete`; `lane-fence` hooks
  `tool.call` and `turn.complete`; `lane-blame` hooks `classic.Stop`, `classic.SubagentStop`,
  `tool.call`, and `turn.complete`. All three draw through `$.ui.status`, never the band.
  `token-weather` draws an `AbovePrompt` band and hooks `session.start`, `session.end`, `turn.step`,
  and `turn.complete`. `blast-radius` hooks `tool.call` and draws `AbovePrompt` and a `Pane`.
  `cc-stretch` is user scope.

Plugin hooks run beside the shell hooks rather than replacing them, so a shared event is not a
collision by itself. A collision here means two things fighting for one slot: the `statusLine`, a
second gauge row in the band, or a handler that can break a tool call it does not own.

### Verdicts

**token-usage: INSTALL.** It is the only candidate that splits cost by seat: `agents_by_type` prices
each subagent type by model, the total carries every model, and the report skill reads both. The
hook is fail-safe, offline, and writes only under `~/.cache/token-usage`. The marketplace pins the
exact commit vetted here, `394ba4dc`. The `wickedsick` marketplace also lists `wizzo-fleet-presence`,
which phones a coordination hub; adding the marketplace installs nothing, so install only
`token-usage`. Each `Stop` re-reads the whole session transcript, which costs a second or two on a
long bundle session, inside its 15 s timeout.

```
claude plugin marketplace add Wicked-Sick-Ltd/ai-marketplace
claude plugin install token-usage@wickedsick --scope project
```

**claude-carbon: REJECT.** It merges every subagent's tokens into one session row by model, so it
cannot show the coordinator's share apart from the agents'.

**Token Weather Usage: REJECT.** It is a context gauge with a cost pill, which token-weather already
fills, and it keeps nothing past the session in the terminal.

**Ledger recommendation: token-usage.** It loses `vo-ledger`'s telemetry mirror and its in-store
history; the ledger files under `~/.cache/token-usage` are the new history.

### Verdicts

**Flightdeck: REJECT.** It opens an eight-row dashboard pane on every session start and hooks fifteen
events, the opposite of a row that stays out of the way.

**agent-radar: INSTALL.** It draws nothing when no agent runs, which is most of a quiet session, and
under wide pace it names each lane, its age, its tool count, and its last call, the one thing neither
token-weather nor the lanes' status segments show. It touches no file, process, or network. Two
caveats: a toast fires for every finished agent with no option to mute it, and its `tool.call`
handler updates a host atom before calling `next` without a guard, so a host-state failure there
would surface in the tool call. Its marketplace entry is a relative path in a monorepo of 25 mods, so
it follows the repo head rather than a pin; the commit vetted is `b6dc6160`. If the coordinator added
this marketplace for token-weather or blast-radius, skip the first line.

```
claude plugin marketplace add hamzafer/claude-code-mods
claude plugin install agent-radar@claude-code-mods --scope project
```

**ccOverhead: REJECT.** It is a second context, quota, and cache gauge, the job token-weather already
does in the same band.

**Band recommendation: agent-radar.** The four `vo-band` segments, the pace word, the inbox count,
the watchlist, and the mods record, have no public replacement among these candidates; naming them as
lost belongs in `decisions.md`.
